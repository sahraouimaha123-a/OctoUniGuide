# وجّهني · Bac Orientation DZ

دليل عربي لاستكشاف 5,063 سجلًا من معدلات التوجيه الرسمية للمرحلة الأولى لبكالوريا الجزائر 2026. يمكن البحث باسم التخصص أو المؤسسة أو الرمز، والتصفية حسب الولاية والمؤسسة، والاطلاع على الأولويات والآفاق المهنية الإرشادية.

## التشغيل المحلي

التطبيق يتكوّن من أربعة ملفات: `index.html` و`styles.css` و`app.js` و`data.js`. لا يحتاج إلى npm أو إلى خطوة بناء. من مجلد المشروع، شغّل `python3 -m http.server 8889` ثم افتح `http://localhost:8889`. تصبح الصفحة قابلة للاستخدام دون اتصال بعد اكتمال الزيارة الأولى على HTTPS أو `localhost`؛ عند تعذّر تحميل الخطوط والأيقونات الخارجية تُستخدم البدائل المحلية.

## البيانات والمفضلة

المصدر هو ملف وزارة التعليم العالي والبحث العلمي «Moyennes minimales BAC 2026, suite à la première phase» المنشور لدى المدرسة الوطنية العليا للإعلام الآلي؛ رابط الملف في صفحة «عن وجّهني». يعرض الملف ثلاث أولويات؛ يدعم التطبيق الرابعة إن توفرت في البيانات. المقارنة بالمعدل إرشادية ولا تضمن القبول.

احتفظ بعنوان صفحة المفضلة أو انسخه باستخدام الزر المخصص لإعادة فتح القائمة لاحقًا. لا توجد حسابات أو مزامنة؛ ويمكن أيضًا طباعة القائمة.
